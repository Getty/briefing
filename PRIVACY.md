# Privacy policy

`briefing` is a Claude Code plugin that runs entirely on your local machine. It
collects nothing, transmits nothing, and stores nothing.

## What the plugin does

The plugin ships one `SessionStart` hook. It runs `echo` and prints a notice that
briefing is obsolete. It reads no files, makes no network requests, writes nothing to
disk and keeps no state. Telemetry, analytics and third-party services are absent.

## Source

The hook is one line in `hooks/hooks.json` in this repository.
